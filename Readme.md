# Occupational Safety & Health: Платформа нового поколения (v2.0)

Веб-приложение для управления охраной труда, построенное на принципах модульности, универсальности и визуального программирования. Это не просто обновление интерфейса, а полная архитектурная переработка первой версии системы ([MySizNeural](https://github.com/NikPes/MySizNeural)).

## 🚀 Чем это отличается от первой версии?

Если **первая версия** была классическим "монолитом" с отдельными страницами под каждую задачу, то **v2.0** — это **универсальная платформа**, где интерфейс, бизнес-логика и отчёты генерируются динамически на основе конфигурации.

| Аспект | Версия 1.0 (MySizNeural) | Версия 2.0 (Occupational Safety) |
| :--- | :--- | :--- |
| **Архитектура** | Монолит, отдельные модули | Универсальное ядро + динамические модули |
| **Фронтенд** | Шаблоны (Jinja2) | React (SPA) |
| **Работа с данными** | Много отдельных CRUD-операций | **Единый универсальный CRUD-движок** |
| **Создание отчётов** | Жёсткие шаблоны | **Визуальный нодовый редактор** (WebGL) |
| **Гибкость** | Изменения требуют правки кода | Многие настройки меняются через UI/конфиги |

## 🧩 Ключевые технологические преимущества v2.0

### 1. Универсальное ядро доступа к данным
*   **Одна точка входа API** для операций создания, чтения, обновления и удаления (CRUD) с **любой** таблицей базы данных, доступной пользователю.
*   **Автоматическая генерация интерфейса:** Формы, фильтры и таблицы для работы с данными создаются "на лету" на основе метаинформации из БД, а не жёстко верстаются.
*   **Динамическая маршрутизация:** Меню и страницы приложения формируются автоматически на основе конфигурации или прав пользователя.

### 2. Современный отзывчивый интерфейс на React
*   **Одностраничное приложение (SPA):** Быстрая работа без постоянных перезагрузок страницы.
*   **Переиспользуемые UI-компоненты:** Кнопки, таблицы, модальные окна — всё единообразно и удобно.
*   **Улучшенный пользовательский опыт.**

### 3. Визуальный конструктор бизнес-логики и отчётов (Roadmap)
*   **Принцип нодовой системы (Node-Based):** Построение сложных отчётов, алгоритмов расчёта СИЗ и проверок происходит не написанием кода, а соединением визуальных блоков ("нодов") на канве.
*   **Технология WebGL:** Плавная работа с большими и сложными схемами.
*   **Аналогия с Cinema 4D / Houdini:** Позволяет специалистам по ОТ гибко "программировать" уникальные бизнес-процессы и документы, не прибегая к помощи разработчика.

## 📋 Функциональность (наследует и улучшает возможности v1.0)
Платформа охватывает **все ключевые модули** системы управления ОТ:
*   **Нормирование и прогнозирование потребности в СИЗ** (с улучшенным расчётным движком).
*   **Управление документацией:** Акты, журналы, протоколы испытаний.
*   **Организация обучения:** Программы инструктажей, графики, учёт знаний (Постановление №2464).
*   **Управление рисками:** Карты рисков, планы мероприятий.
*   **Контроль и напоминания:** Интеллектуальный планер задач.

## 🛠️ Технологический стек (v2.0)
*   **Frontend:** React, TypeScript (опционально), Zustand/Redux (state management), WebGL (визуальный редактор)
*   **Backend API:** Python, FastAPI (или Flask в роли API), SQLAlchemy, Pydantic
*   **База данных:** PostgreSQL
*   **Связь:** REST API или GraphQL между фронтендом и бэкендом

## 🚧 Текущий статус проекта
Проект находится в **активной стадии разработки**. Реализованы:
*   Базовая архитектура универсального CRUD-движка.
*   Прототип системы аутентификации и ролевой модели (root, admin, user).
*   Интерфейс для управления модулями и доступом.
*   Начальная интеграция фронтенда (React) и бэкенда (Python).

В ближайшей перспективе — разработка ядра визуального нодового редактора.
